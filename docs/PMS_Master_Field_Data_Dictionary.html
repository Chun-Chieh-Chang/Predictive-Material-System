🌿 品號主檔 (含良率/採購規則) (Item Master) [item_master]
權責：資材(生管) / 研發部

全廠所有塑膠原料、色母、包材、單品射出零件、組裝組件與出貨成品的唯一身分證檔案，並整合標準檢驗良率與採購交期參數。

sku
品號 (SKU)
PK string (VARCHAR 50)
💡 白話通俗解說
這項東西在全工廠裡的「唯一身分證字號」。不管是買進來的塑膠原料粒、紙箱袋子，還是射出機做出來的零件、組裝好的成品，每一種都要有自己的品號，全廠絕不能重複。
業務目的：作為所有交易單據、BOM、庫存與 MRP 推導的唯一核心索引鍵。
填寫規範：必填。英文字母大寫、數字與連字號組成，不可包含空格或特殊符號。成品建議以 A/B 編碼開頭，原料以材質規格命名。
📍 數據鏈與介面位置
業務工作台（品號查詢/訂單明細）、生管採購工作台（MRP 品號選單）、總覽儀表板（品號過濾）、出貨排程審查看板（品號清單）、資料表維護
📝 實務範例
A01-200-131
代表 A客戶 專用的「醫療級標準 T 接頭成品套組」。在客戶訂單、庫存快照與出貨單上皆以此品號溝通。
MRP/演算影響：所有階層展開之基本錨點，決定品號身分與推導路徑。
alt_sku
替代品號 (Alt SKU)
Optional string | null
💡 白話通俗解說
「備用料號」或「客戶舊料號」。如果原本的原料缺貨買不到，或者客戶在他們自己系統裡叫另一個代號，就記在這裡。
業務目的：提供物料工程替代防線，避免單一料號斷料導致停線。
填寫規範：選填。若無替代品或舊品號請留空。若有多個替代品以逗號分隔。
📍 數據鏈與介面位置
資料表維護（品號主檔）、生管採購工作台（替代料/備用料備料提醒）
📝 實務範例
TERLUX-2802-ALT
代表與原廠 TERLUX 2802 物性等級完全相容的備用 MABS 塑膠粒。當原廠交期拉長時，生管可直接查詢此欄位調用備料。
MRP/演算影響：主料缺料時，系統可提示生管與採購評估替代料庫存進行沖抵。
customer_id
客戶代碼 (Customer ID)
Required string (VARCHAR 20)
💡 白話通俗解說
「這個產品是賣給哪一家客戶的專屬品」。如果是全廠大家通用的原料（例如透明樹脂、通用紙箱），就填 GEN（代表通用 General）。
業務目的：用於區隔客戶專屬模具權利、出貨對象與客戶預測偏差分析。
填寫規範：必填。必填。填寫客戶代碼或名稱（如 A客戶, B客戶, 通用客戶）。
📍 數據鏈與介面位置
業務工作台（客戶查詢樞紐）、總覽儀表板（客戶維度過濾與預測比對）、資料表維護
📝 實務範例
A客戶
代表 A客戶 公司。該成品專利與模具屬於 A客戶，不可出貨給其他客戶。
MRP/演算影響：用於總覽儀表板按客戶維度彙整需求與預測偏差分析。
category
產品種類 (Category)
Required string (VARCHAR 50)
💡 白話通俗解說
「這項東西是什麼種類的物品」。例如是「T接頭」、「三通閥」、「ABS塑膠粒」還是「滅菌袋」。
業務目的：協助生管快速進行類別彙總、模具成型分組與倉儲分區。
填寫規範：必填。使用公司統一制定的品類詞彙（如 T接頭、三通閥、針筒外筒、PP樹脂、Tyvek包材）。
📍 數據鏈與介面位置
出貨排程審查看板（產品類別篩選膠囊）、總覽儀表板、資料表維護
📝 實務範例
T接頭
代表本品號屬於管路連接用的 T 型三向接頭結構件，利於生管在同類模具間比對成型產能。
MRP/演算影響：篩選分類報表與產線機台負載歸類。
material_class
物料五層分類 (Material Class)
Required enum (RAW | MAT | PART | COMP | SET)
💡 白話通俗解說
「這東西在我們廠內生產流程中的身分層級」。全廠嚴格分成五層：RAW(買進來的塑膠粒/色粉)、MAT(紙箱包材)、PART(自己射出的單顆零件)、COMP(幾個零件組裝的組件)、SET(最後整套出貨的成品)。
業務目的：嚴格規範該品號在 BOM 與 MRP 中的運算行為與外鍵下拉限制，徹底符合 ERP 3NF 標準。
填寫規範：必填。下拉選單五選一（RAW, MAT, PART, COMP, SET）。原料嚴格選 RAW，射出零件選 PART，成品選 SET。
📍 數據鏈與介面位置
物料分類體系管理視圖、生管採購工作台（BOM 與良率分流判定）、資料表維護
📝 實務範例
SET
代表 A01-200-131 屬於最頂層的「出貨套組成品」，系統會以它為起點向下展開零件與原料需求。
MRP/演算影響：決定是否參與 BOM 展開、是否有良率折算或最晚採購倒推。
color
外觀顏色 (Color)
Optional string | null
💡 白話通俗解說
「產品射出來或組裝好之後是什麼顏色」。例如透明本色、天藍色、乳白色。
業務目的：現場調料配色、換模換料洗機台與品管對色標準。
填寫規範：選填。輸入顏色英文與中文（如 Natural (本色)、Sky Blue (天藍)）。
📍 數據鏈與介面位置
生管採購工作台（外觀與混料配比換算）、資料表維護
📝 實務範例
Sky Blue (天藍色)
代表該成型製品外觀為醫用天藍色，成型時必須添加指定色母 (CB-BLUE-01) 進行混料。
MRP/演算影響：搭配色粉混合配比 (Color Mixing) 觸發原料與色母雙重計算。
unit
計量單位 (Unit)
Required enum (PCS | KG | SET)
💡 白話通俗解說
「庫存算帳時用什麼單位」。原料通常算「公斤 KG」，零件通常算「個 PCS」，整套成品算「套 SET」或「個 PCS」。
業務目的：確保庫存數量與採購算式單位統一，防止單位混淆導致少算 1000 倍。
填寫規範：必填。塑膠粒與色料選 KG；單顆零件選 PCS；組合套件選 SET 或 PCS。
📍 數據鏈與介面位置
3 階 MRP 推導（PCS / KG / SET 跨階單位轉換基準）、資料表維護
📝 實務範例
PCS
代表成品以「件 (PCS)」為計算單位，客戶訂單 10,000 即代表 10,000 件。
MRP/演算影響：MRP 跨階換算克重 (g) 與公斤 (KG) 時之基數標準。
description
說明備註 (Description)
Optional string | null
💡 白話通俗解說
「這項東西的詳細規格與備註說明」。例如原廠規格書型號、醫療級認證、注意事項。
業務目的：供倉管、採購與品保人員查核物料原廠規格與合規認證。
填寫規範：選填。可填寫 200 字以內的中文或英文詳細規格說明。
📍 數據鏈與介面位置
資料表維護（品號規格書型號、醫療級認證與原廠包裝備註）
📝 實務範例
醫療級透明 MABS 樹脂，符合 USP Class VI 認證，原廠包裝 25KG/包
清楚說明該塑料的醫療級別與包裝方式，採購收料驗收時可作為核對包裝與標籤之依據。
MRP/演算影響：純資訊顯示，不影響數學公式運算。
std_sorting_yield
標準全檢良率 (Std Sorting Yield)
Required number (FLOAT 0.01~1.0)
💡 白話通俗解說
「品檢人員在做 100% 全檢時，每 100 顆裡面預計有幾顆是合格的良品」。例如填 0.98 代表預期有 98% 是好的，有 2% 是黑點毛邊不良品。
業務目的：讓系統在計算在製品 (WIP) 待驗半品時，把不良品扣掉，只把真正能用的良品算進庫存。
填寫規範：必填。以小數點表示（如 0.98 代表 98%）。嚴禁填寫整數 98 或百分比符號。
📍 數據鏈與介面位置
出貨排程審查看板（WIP 待驗良品折算）、3 階 MRP 第 1 階算式過程、資料表維護
📝 實務範例
0.98
代表該製品在品檢全檢時歷史平均良率為 98%。若現有 1,000 PCS 待驗品，系統只會認定有 980 PCS 為可用良品。
MRP/演算影響：第 1 階有效 WIP 折算公式：有效待驗良品 = WIP 待驗數量 × 標準全檢良率。
supplier_name
供應商名稱 (Supplier Name)
Required string (VARCHAR 100)
💡 白話通俗解說
「這項原料是向哪一家廠商或代理商買的」。
業務目的：採購發單對象、廠商評鑑與交期追蹤。
填寫規範：必填。填寫廠商全名（如 INEOS Styrolution, A供應商, 台塑石化）。
📍 數據鏈與介面位置
3 階 MRP 第 3 階採購建議（供應商對象）、在途原料物流追蹤、資料表維護
📝 實務範例
INEOS Styrolution (英力士苯領)
代表該醫療級 MABS 塑料係直接向德國原廠英力士苯領採購。
MRP/演算影響：顯示於採購建議單與在途 PO 供應商欄位。
lead_time_days
採購交期天數 (Lead Time Days)
Required number (INTEGER ≥ 1)
💡 白話通俗解說
「從採購發訂單給廠商，到原料真正運進我們廠裡可以開始用的總天數」。包含廠商生產、船期海運、報關檢驗的時間。
業務目的：前瞻防斷料的最重要參數！系統會拿客戶交期扣掉這個天數，告訴採購「最晚哪一天一定要下單」。
填寫規範：必填。正整數天數。進口料通常為 60~120 天，本土料通常為 7~14 天。
📍 數據鏈與介面位置
生管採購工作台（最晚下單日 30 天時程軸）、3 階 MRP 第 3 階發單日倒推、資料表維護
📝 實務範例
90
自歐洲船運進口需 90 天（含原廠備貨 15天 + 海運 60天 + 報關入庫 15天）。若客戶 11/20 要貨，最晚 8/22 就必須向廠商下單。
MRP/演算影響：推算最晚採購下單日公式：最晚下單發單日 = 客戶交期 - 採購交期天數 (Lead Time)。
moq_kg
最小起訂量 KG (MOQ)
Required number (FLOAT > 0)
💡 白話通俗解說
「廠商規定一次最少一定要買多少公斤」。就算我們只缺 30 公斤，廠商規定一次最少要買 500 公斤，我們就必須買 500 公斤。
業務目的：系統自動將計算出來的微小缺口向上整補到廠商要求的最小倍數，符合商業採購合約。
填寫規範：必填。正數（如 500.0, 1000.0, 25.0）。依供應商報價合約填寫。
📍 數據鏈與介面位置
3 階 MRP 第 3 階建議採購量向上整補、資料表維護
📝 實務範例
500.0
原廠規定單次採購至少需訂購 1 個棧板（20 包 × 25KG = 500KG）。若系統算得缺口為 79.6KG，會自動整補建議下單 500KG。
MRP/演算影響：建議採購量公式：建議下單量 = CEILING(原料淨缺口 ÷ MOQ) × MOQ。
safety_stock_kg
安全庫存量 KG (Safety Stock)
Required number (FLOAT ≥ 0)
💡 白話通俗解說
「倉庫裡平時最少要保留多少公斤的原料當作緊急保險庫存」。用來防範船期延誤、塞港或客戶臨時緊急插單。
業務目的：建立防斷料安全緩衝防線。
填寫規範：必填。正數（如 200.0）。若無安全庫存請填 0。建議抓 2 週平均消耗量。
📍 數據鏈與介面位置
3 階 MRP 第 3 階原料淨缺口緩衝算式、資料表維護
📝 實務範例
200.0
常備 200 公斤（約 8 包）作為安全庫存。當庫存低於 200KG 時系統即觸發備料警戒。
MRP/演算影響：原料淨缺口計算公式：原料淨缺口 = 毛需求 - (在手庫存 + 在途PO) + 安全庫存量。
⚙️ 模具與產能主檔 (Mold Master) [mold_master]
權責：製造部 / 模具課

射出成型模具之鋼模編號、原始設計穴數、現場可用穴數、成型秒數與理論產能參數檔。

mold_id
模具編號 (Mold ID)
PK string (VARCHAR 30)
💡 白話通俗解說
「實體鋼模上面的身分證鋼印編號」。每套模具都有唯一編號，現場派工上模時都叫這個號碼。
業務目的：成型派工、模具履歷管理、保養維修與 BOM 成型關聯。
填寫規範：必填。大寫英文字母與數字（如 MI17193, MI20224），必須與實體模具銘牌鋼印一致。
📍 數據鏈與介面位置
生管採購工作台（模具日產能卡片）、成型 BOM 關聯選單、資料表維護
📝 實務範例
MI17193
代表廠內編號 MI17193 的 24 穴精密射出模具，專門用於生產 T 接頭本體零件。
MRP/演算影響：MRP 展開第 2 階成型穴數與週期之索引主鍵。
design_cavities
設計穴數 (Design Cavities)
Required number (INTEGER ≥ 1)
💡 白話通俗解說
「這副模具當初做好時，開一次模本來可以射出幾顆零件」。這是模具滿穴時的理想數字。
業務目的：記錄模具理論滿載能量，作為計算塞穴比例與產能損失基準。
填寫規範：必填。正整數（如 8, 16, 24, 32）。不可填 0。
📍 數據鏈與介面位置
資料表維護（原始設計穴數，對比塞穴損耗）
📝 實務範例
24
代表該模具出廠時設計為 24 穴，如果完全沒壞，開一模就能產出 24 顆零件。
MRP/演算影響：用於計算塞穴損失率與設計滿載產能基準。
active_cavities
妥善穴數 (Active Cavities)
Required number (INTEGER ≥ 1)
💡 白話通俗解說
「這副模具今天在機台上實際能射出幾顆好零件」。如果模具有 2 個穴受損堵住了（塞穴），這裡就要填 22。
業務目的：真實反映現場成型產能，避免以滿穴虛算導致交期延誤與耗料低估。
填寫規範：必填。必須 ≤ 設計穴數。若現場發生塞穴，模具課或生管必須立即在此修改更新。
📍 數據鏈與介面位置
3 階 MRP 第 2 階單穴克重算式、生管採購工作台（現場實際妥善穴數與日產能推估）、資料表維護
📝 實務範例
22
原本 24 穴的模具，因第 5 穴與第 12 穴頂針磨損漏膠而現場塞穴，目前實際注膠出模為 22 穴。
MRP/演算影響：重要核心分母：單穴耗料克重 = 整模總重 ÷ 妥善穴數；妥善穴數減少會導致每顆零件分攤流道變重、原料毛需求上升。
cycle_time_sec
成型週期 (Cycle Time)
Required number (FLOAT ≥ 1)
💡 白話通俗解說
「射出機開關模一次需要幾秒鐘」。從合模、射膠、保壓、冷卻到頂出開模的完整時間。
業務目的：計算單日理論產能與評估產線排程負荷。
填寫規範：必填。單位為秒，填寫小數（如 18.5）。由現場試模條件表或量產標準作業卡提供。
📍 數據鏈與介面位置
生管採購工作台（模具日產能公式: (86400 / 週期) × 妥善穴數）、資料表維護
📝 實務範例
18.5
射出機開模注塑一模耗時 18.5 秒，代表一分鐘可開模約 3.24 次。
MRP/演算影響：日產能計算公式核心分母：日產能 = (86,400 ÷ 成型週期) × 妥善穴數。
daily_capacity
日產能 PCS (Daily Capacity)
Computed number (INTEGER)
💡 白話通俗解說
