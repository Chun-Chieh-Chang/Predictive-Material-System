🌿 料號基本主檔 (Item Master) [item_master]
權責單位：研發部 / 生管部
全廠所有塑膠原料、色母、包材、單品射出零件、組裝組件與出貨成品的唯一身分證檔案。
sku 品號 (SKU)
PK 主鍵 string (VARCHAR 50)
📍
在數據鏈與介面中的位置： 業務工作台（品號查詢/訂單明細）、生管採購工作台（MRP 品號選單）、總覽儀表板（品號過濾）、出貨排程審查看板（品號清單）、資料表維護
💡 大白話解說 (這是什麼？)

這項東西在全工廠裡的「唯一身分證字號」。不管是買進來的塑膠原料粒、紙箱袋子，還是射出機做出來的零件、組裝好的成品，每一種都要有自己的品號，全廠絕不能重複。

🎯 業務價值與用途 (Why it matters)
作為所有交易單據、BOM、庫存與 MRP 推導的唯一核心索引鍵。
⚙️ 系統推導與運算連動 (MRP Impact)
所有階層展開之基本錨點，決定品號身分與推導路徑。
📝 填寫規範與防呆要點 (Fill Guide)
必填。英文字母大寫、數字與連字號組成，不可包含空格或特殊符號。成品建議以 A/B 編碼開頭，原料以材質規格命名。
🔍 實務示範：A01-200-131
代表 A客戶 專用的「醫療級標準 T 接頭成品套組」。在客戶訂單、庫存快照與出貨單上皆以此品號溝通。
alt_sku 替代品號 (Alt SKU)
選填 (Optional) string | null
📍
在數據鏈與介面中的位置： 資料表維護（品號主檔）、生管採購工作台（替代料/備用料備料提醒）
💡 大白話解說 (這是什麼？)

「備用料號」或「客戶舊料號」。如果原本的原料缺貨買不到，或者客戶在他們自己系統裡叫另一個代號，就記在這裡。

🎯 業務價值與用途 (Why it matters)
提供物料工程替代防線，避免單一料號斷料導致停線。
⚙️ 系統推導與運算連動 (MRP Impact)
主料缺料時，系統可提示生管與採購評估替代料庫存進行沖抵。
📝 填寫規範與防呆要點 (Fill Guide)
選填。若無替代品或舊品號請留空。若有多個替代品以逗號分隔。
🔍 實務示範：TERLUX-2802-ALT
代表與原廠 TERLUX 2802 物性等級完全相容的備用 MABS 塑膠粒。當原廠交期拉長時，生管可直接查詢此欄位調用備料。
customer_id 客戶代碼 (Customer ID)
必填 (Required) string (VARCHAR 20)
📍
在數據鏈與介面中的位置： 業務工作台（客戶查詢樞紐）、總覽儀表板（客戶維度過濾與預測比對）、資料表維護
💡 大白話解說 (這是什麼？)

「這個產品是賣給哪一家客戶的專屬品」。如果是全廠大家通用的原料（例如透明樹脂、通用紙箱），就填 GEN（代表通用 General）。

🎯 業務價值與用途 (Why it matters)
用於區隔客戶專屬模具權利、出貨對象與客戶預測偏差分析。
⚙️ 系統推導與運算連動 (MRP Impact)
用於總覽儀表板按客戶維度彙整需求與預測偏差分析。
📝 填寫規範與防呆要點 (Fill Guide)
必填。必填。填寫客戶代碼或名稱（如 A客戶, B客戶, 通用客戶）。
🔍 實務示範：A客戶
代表 A客戶 公司。該成品專利與模具屬於 A客戶，不可出貨給其他客戶。
category 產品種類 (Category)
必填 (Required) string (VARCHAR 50)
📍
在數據鏈與介面中的位置： 出貨排程審查看板（產品類別篩選膠囊）、總覽儀表板、資料表維護
💡 大白話解說 (這是什麼？)

「這項東西是什麼種類的物品」。例如是「T接頭」、「三通閥」、「ABS塑膠粒」還是「滅菌袋」。

🎯 業務價值與用途 (Why it matters)
協助生管快速進行類別彙總、模具成型分組與倉儲分區。
⚙️ 系統推導與運算連動 (MRP Impact)
篩選分類報表與產線機台負載歸類。
📝 填寫規範與防呆要點 (Fill Guide)
必填。使用公司統一制定的品類詞彙（如 T接頭、三通閥、針筒外筒、PP樹脂、Tyvek包材）。
🔍 實務示範：T接頭
代表本品號屬於管路連接用的 T 型三向接頭結構件，利於生管在同類模具間比對成型產能。
material_class 物料五層分類 (Material Class)
必填 (Required) enum (RAW | MAT | PART | COMP | SET)
📍
在數據鏈與介面中的位置： 物料分類體系管理視圖、生管採購工作台（BOM 與良率分流判定）、資料表維護
💡 大白話解說 (這是什麼？)

「這東西在我們廠內生產流程中的身分層級」。全廠嚴格分成五層：RAW(買進來的塑膠粒/色粉)、MAT(紙箱包材)、PART(自己射出的單顆零件)、COMP(幾個零件組裝的組件)、SET(最後整套出貨的成品)。

🎯 業務價值與用途 (Why it matters)
嚴格規範該品號在 BOM 與 MRP 中的運算行為與外鍵下拉限制，徹底符合 ERP 3NF 標準。
⚙️ 系統推導與運算連動 (MRP Impact)
決定是否參與 BOM 展開、是否有良率折算或最晚採購倒推。
📝 填寫規範與防呆要點 (Fill Guide)
必填。下拉選單五選一（RAW, MAT, PART, COMP, SET）。原料嚴格選 RAW，射出零件選 PART，成品選 SET。
🔍 實務示範：SET
代表 A01-200-131 屬於最頂層的「出貨套組成品」，系統會以它為起點向下展開零件與原料需求。
color 外觀顏色 (Color)
選填 (Optional) string | null
📍
在數據鏈與介面中的位置： 生管採購工作台（外觀與混料配比換算）、資料表維護
💡 大白話解說 (這是什麼？)

「產品射出來或組裝好之後是什麼顏色」。例如透明本色、天藍色、乳白色。

🎯 業務價值與用途 (Why it matters)
現場調料配色、換模換料洗機台與品管對色標準。
⚙️ 系統推導與運算連動 (MRP Impact)
搭配色粉混合配比 (Color Mixing) 觸發原料與色母雙重計算。
📝 填寫規範與防呆要點 (Fill Guide)
選填。輸入顏色英文與中文（如 Natural (本色)、Sky Blue (天藍)）。
🔍 實務示範：Sky Blue (天藍色)
代表該成型製品外觀為醫用天藍色，成型時必須添加指定色母 (CB-BLUE-01) 進行混料。
unit 計量單位 (Unit)
必填 (Required) enum (PCS | KG | SET)
📍
在數據鏈與介面中的位置： 3 階 MRP 推導（PCS / KG / SET 跨階單位轉換基準）、資料表維護
💡 大白話解說 (這是什麼？)

「庫存算帳時用什麼單位」。原料通常算「公斤 KG」，零件通常算「個 PCS」，整套成品算「套 SET」或「個 PCS」。

🎯 業務價值與用途 (Why it matters)
確保庫存數量與採購算式單位統一，防止單位混淆導致少算 1000 倍。
⚙️ 系統推導與運算連動 (MRP Impact)
MRP 跨階換算克重 (g) 與公斤 (KG) 時之基數標準。
📝 填寫規範與防呆要點 (Fill Guide)
必填。塑膠粒與色料選 KG；單顆零件選 PCS；組合套件選 SET 或 PCS。
🔍 實務示範：PCS
代表成品以「件 (PCS)」為計算單位，客戶訂單 10,000 即代表 10,000 件。
description 說明備註 (Description)
選填 (Optional) string | null
📍
在數據鏈與介面中的位置： 資料表維護（品號規格書型號、醫療級認證與原廠包裝備註）
💡 大白話解說 (這是什麼？)

「這項東西的詳細規格與備註說明」。例如原廠規格書型號、醫療級認證、注意事項。

🎯 業務價值與用途 (Why it matters)
供倉管、採購與品保人員查核物料原廠規格與合規認證。
⚙️ 系統推導與運算連動 (MRP Impact)
純資訊顯示，不影響數學公式運算。
📝 填寫規範與防呆要點 (Fill Guide)
選填。可填寫 200 字以內的中文或英文詳細規格說明。
🔍 實務示範：醫療級透明 MABS 樹脂，符合 USP Class VI 認證，原廠包裝 25KG/包
清楚說明該塑料的醫療級別與包裝方式，採購收料驗收時可作為核對包裝與標籤之依據。
⚙️ 模具與產能主檔 (Mold Master) [mold_master]
權責單位：模具課 / 製造部
射出成型模具之鋼模編號、原始設計穴數、現場可用穴數、成型秒數與理論產能參數檔。
mold_id 模具編號 (Mold ID)
PK 主鍵 string (VARCHAR 30)
📍
在數據鏈與介面中的位置： 生管採購工作台（模具日產能卡片）、成型 BOM 關聯選單、資料表維護
💡 大白話解說 (這是什麼？)

「實體鋼模上面的身分證鋼印編號」。每套模具都有唯一編號，現場派工上模時都叫這個號碼。

🎯 業務價值與用途 (Why it matters)
成型派工、模具履歷管理、保養維修與 BOM 成型關聯。
⚙️ 系統推導與運算連動 (MRP Impact)
MRP 展開第 2 階成型穴數與週期之索引主鍵。
📝 填寫規範與防呆要點 (Fill Guide)
必填。大寫英文字母與數字（如 MI17193, MI20224），必須與實體模具銘牌鋼印一致。
🔍 實務示範：MI17193
代表廠內編號 MI17193 的 24 穴精密射出模具，專門用於生產 T 接頭本體零件。
design_cavities 設計穴數 (Design Cavities)
必填 (Required) number (INTEGER ≥ 1)
📍
在數據鏈與介面中的位置： 資料表維護（原始設計穴數，對比塞穴損耗）
💡 大白話解說 (這是什麼？)

「這副模具當初做好時，開一次模本來可以射出幾顆零件」。這是模具滿穴時的理想數字。

🎯 業務價值與用途 (Why it matters)
記錄模具理論滿載能量，作為計算塞穴比例與產能損失基準。
⚙️ 系統推導與運算連動 (MRP Impact)
用於計算塞穴損失率與設計滿載產能基準。
📝 填寫規範與防呆要點 (Fill Guide)
必填。正整數（如 8, 16, 24, 32）。不可填 0。
🔍 實務示範：24
代表該模具出廠時設計為 24 穴，如果完全沒壞，開一模就能產出 24 顆零件。
active_cavities 妥善穴數 (Active Cavities)
必填 (Required) number (INTEGER ≥ 1)
📍
在數據鏈與介面中的位置： 3 階 MRP 第 2 階單穴克重算式、生管採購工作台（現場實際妥善穴數與日產能推估）、資料表維護
💡 大白話解說 (這是什麼？)

「這副模具今天在機台上實際能射出幾顆好零件」。如果模具有 2 個穴受損堵住了（塞穴），這裡就要填 22。

🎯 業務價值與用途 (Why it matters)
真實反映現場成型產能，避免以滿穴虛算導致交期延誤與耗料低估。
⚙️ 系統推導與運算連動 (MRP Impact)
重要核心分母：單穴耗料克重 = 整模總重 ÷ 妥善穴數；妥善穴數減少會導致每顆零件分攤流道變重、原料毛需求上升。
📝 填寫規範與防呆要點 (Fill Guide)
必填。必須 ≤ 設計穴數。若現場發生塞穴，模具課或生管必須立即在此修改更新。
🔍 實務示範：22
原本 24 穴的模具，因第 5 穴與第 12 穴頂針磨損漏膠而現場塞穴，目前實際注膠出模為 22 穴。
cycle_time_sec 成型週期 (Cycle Time)
必填 (Required) number (FLOAT ≥ 1)
📍
在數據鏈與介面中的位置： 生管採購工作台（模具日產能公式: (86400 / 週期) × 妥善穴數）、資料表維護
💡 大白話解說 (這是什麼？)

「射出機開關模一次需要幾秒鐘」。從合模、射膠、保壓、冷卻到頂出開模的完整時間。

🎯 業務價值與用途 (Why it matters)
計算單日理論產能與評估產線排程負荷。
⚙️ 系統推導與運算連動 (MRP Impact)
日產能計算公式核心分母：日產能 = (86,400 ÷ 成型週期) × 妥善穴數。
📝 填寫規範與防呆要點 (Fill Guide)
必填。單位為秒，填寫小數（如 18.5）。由現場試模條件表或量產標準作業卡提供。
🔍 實務示範：18.5
射出機開模注塑一模耗時 18.5 秒，代表一分鐘可開模約 3.24 次。
daily_capacity 日產能 PCS (Daily Capacity)
計算值 (Computed) number (INTEGER)
📍
在數據鏈與介面中的位置： 生管採購工作台（模具日產能卡片）、總覽儀表板（機台負荷估算）、資料表維護
💡 大白話解說 (這是什麼？)

「這副模具裝在射出機上連續開工 24 小時，一天最多能做幾顆零件」。系統會自動幫你算好，不需要手算。

🎯 業務價值與用途 (Why it matters)
生管評估訂單需要排幾天才能做完、是否會產能塞車交不出來。
⚙️ 系統推導與運算連動 (MRP Impact)
訂單緊張度 (Order Tension) 產能負荷診斷與出貨排程放行之重要產能指標。
📝 填寫規範與防呆要點 (Fill Guide)
唯讀欄位（系統自動計算）。隨妥善穴數與成型週期變更即時重算。
🔍 實務示範：102,810
計算式：(86,400秒 ÷ 18.5秒) × 22穴 = 102,810 PCS/日。生管若接到 30 萬訂單，可知至少需排產 3 個工作天。
status 模具狀態 (Status)
必填 (Required) enum (active | maintenance | trial | retired)
📍
在數據鏈與介面中的位置： 訂單缺料分析（模具可用性環節診斷）、資料表維護
💡 大白話解說 (這是什麼？)

「這副模具現在能不能用」。active(正常量產中)、maintenance(正在保養維修不能用)、trial(試模中)、retired(已報廢封存)。

🎯 業務價值與用途 (Why it matters)
防呆機制：防止生管把正在送修或報廢的模具排入正式生產計劃。
⚙️ 系統推導與運算連動 (MRP Impact)
非 active 狀態之模具將觸發「產能不可用警報」，提示生管調度備用模具。
📝 填寫規範與防呆要點 (Fill Guide)
必填。下拉選單四選一。維修保養時務必切換為 maintenance。
🔍 實務示範：active
代表該模具狀態良好，隨時可以指派射出機進行量產排程。
location 模具庫位 (Location)
選填 (Optional) string | null
📍
在數據鏈與介面中的位置： 資料表維護（模具庫位與機台位置）
💡 大白話解說 (這是什麼？)

「模具現在放在工廠哪一個架子上或哪台機台上」。現場換模人員要去哪裡搬模具。

🎯 業務價值與用途 (Why it matters)
協助現場換模技術員快速定位模具，減少換模尋模工時。
⚙️ 系統推導與運算連動 (MRP Impact)
純現場定位資訊，不影響數值運算。
📝 填寫規範與防呆要點 (Fill Guide)
選填。填寫模具架位編號（如 模具架B區-03層）或機台代號（如 射出機 IMM-04）。
🔍 實務示範：模具架 B區-03層
現場架位管理，換模師傅可直接推天車至 B 區第三層取模。
machine_type 成型機型號 (Machine Type)
選填 (Optional) string | null
📍
